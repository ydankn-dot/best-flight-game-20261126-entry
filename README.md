Skylark Ridge Run — fly the Kestrel K-9 mail plane down an alpine valley: take off from Pine Hollow airfield, thread eight gold rings, mind the fuel and the stall speed, and land on the Ridge Top strip. A complete 3D flight game that runs offline in a desktop browser from its own files: a chase view over procedural terrain, a lit instrument panel (airspeed, altitude, heading, attitude, throttle, fuel, damage), missions with different goals, and landings and crashes that read as what happened. No build step, no network, no libraries at run time beyond the vendored Three.js.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

W / S or ↑ / ↓ throttle, A / D or ← / → bank and turn, I / K pitch, mouse steers like a stick. Press Enter to fly, R to fly again, M to mute.
